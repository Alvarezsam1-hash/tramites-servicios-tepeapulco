# Portal de Trámites y Servicios Municipales — Tepeapulco

## Cómo usarlo
1. Sube todos los archivos de esta carpeta a un repositorio de GitHub.
2. Coloca el logotipo oficial sin modificar en:
   `logo/logo-tepeapulco.png`
3. Coloca los PDF de cada área en la carpeta `infografias/` usando exactamente estos nombres:
   - registro-civil.pdf
   - panteones.pdf
   - conciliacion.pdf
   - desarrollo-economico.pdf
   - servicios-municipales.pdf
   - rastro.pdf
   - turismo.pdf
   - proteccion-civil.pdf
   - obras-publicas.pdf
   - catastro.pdf
   - ecologia.pdf
   - dif.pdf
4. En GitHub entra a Settings > Pages.
5. Selecciona Deploy from a branch > main > /root y guarda.
6. GitHub te dará la dirección pública del portal.
7. Con esa dirección generaremos el QR definitivo para la Expo Feria.

## Importante
El diseño está preparado para crecer. Podemos agregar más departamentos sin cambiar la estructura.
